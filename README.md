# صانع الشهادات اليمني الذكي

تطبيق Flutter أوفلاين لإنشاء شهادات تقديرية للأوائل وشهادات تشجيعية للناجحين.

## المزايا
- شهادات الأوائل بالمراكز: الأول، الأول مكرر، الثاني، الثاني مكرر، الثالث، الثالث مكرر.
- شهادات تشجيعية للناجحين.
- خمسة قوالب مختلفة.
- اتجاه A4 أفقي أو عمودي.
- إضافة شعار المدرسة من الهاتف وحفظه محلياً.
- الترويسة اليمنية ثابتة في كل القوالب.
- تعديل نصوص الشهادة بالكامل وحفظها كإعدادات افتراضية.
- إضافة الطلاب وحفظهم محلياً.
- إنشاء شهادة فردية أو شهادات جماعية في ملف PDF واحد.
- معاينة وطباعة ومشاركة PDF.
- لا يحتاج إلى إنترنت بعد تثبيته.

## التشغيل
1. ضع المشروع في Flutter.
2. نفذ `flutter pub get`.
3. نفذ `flutter run` أو `flutter build apk --release`.
